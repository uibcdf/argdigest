# ArgDigest 0.16.0

ArgDigest 0.16.0 adds public registration-only diagnostics for application-owned
SMonitor configuration.

- With SMonitor 0.20.0 or newer, importing ArgDigest registers its diagnostic
catalog without configuring application policy, handlers or exception hooks.
  `register_diagnostics()` exposes the same idempotent operation.
- `configure_diagnostics()` preserves existing application configuration by
default. Applications can explicitly request provider recommendations with
  `use_provider_policy=True` when the provider supports that operation.
- The CLI explicitly configures its own diagnostic session. Optional type-check
engine loading is deferred until use, keeping basic imports free of scientific
dependencies and unrelated provider initialization.
- Older supported SMonitor providers retain their legacy initialization route;
explicit registration-only requests fail with an actionable capability error.

Python 3.11–3.14 and core dependency floors remain unchanged. The release uses
staging, full installed qualification with public SMonitor 0.21.0 and DepDigest
0.15.1, separate NumPy-free lower-bound qualification and exact-file promotion.
Consumer adoption and source-only archival remain independent claims.
