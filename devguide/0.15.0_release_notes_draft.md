# ArgDigest 0.15.0

ArgDigest 0.15.0 adds scoped diagnostic capture and explicit argument digestion.

- `capture_policy="metadata_only"` restricts ArgDigest-owned telemetry before
  formatting or instrumentation, retaining validation, normalization and native
  failures. It accepts SMonitor's task-local policy, respects stricter enclosing
  scopes and uses fixed fallback diagnostics. Scoped capture requires public
  SMonitor 0.19.0 or a compatible newer provider; older supported providers fail
  closed on an explicit restrictive request and retain detailed defaults.
- `argument_digestion=None/True/False` selects argument digesters independently
  of configuration. None preserves inference; True enables digestion and strict
  missing-digester checks; False keeps pipelines, binding, function/domain
  contracts, aliases, standardization and requested type checks active.
- Both decorator forms and module/file/programmatic configuration accept these
  options. Plans and CLI audit expose the requested/effective execution selection.

Python 3.11–3.14, the optional NumPy boundary and core dependency floors remain
unchanged. Consumer adoption is independent of this provider release.

The release uses staging and exact-file promotion. The full installed matrix
requires public SMonitor 0.19.0 and executes the scoped tests; a separate
NumPy-free matrix qualifies the old-provider lower bounds. GitHub source
archival and Conda publication have independent receipts.
