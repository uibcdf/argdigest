# 0.13.0 release notes (candidate)

This candidate expands ArgDigest core support to Python 3.14 after the
component-specific gate in `uibcdf/argdigest#13`. It remains unpublished until
the exact tagged commit, staged package, public installation, and Zenodo gates
pass. The current public 0.12.1 line supports Python 3.11--3.13.

## Changes

- Declare Python `>=3.11,<3.15` and require public DepDigest `>=0.11.0` and
  SMonitor `>=0.16.0`, the first releases in this dependency chain verified on
  Python 3.14.
- Replace interpreter/platform-specific Conda builds with one pure-Python
  `noarch: python` package. The target matrix is Linux, macOS, and Windows on
  Python 3.11--3.14; packaging and installed-package gates must prove it.
- Make the absent optional PyUnitWizard integration explicit, so its testable
  module sentinel exists even when the library is not installed. This does not
  claim that the optional PyUnitWizard integration already supports Python 3.14.
- Correct the compatibility test's obsolete badge-color expectation. The
  public badge remains at 3.11--3.13 until 0.13.0 is independently admitted.

## Publication decision

The Conda route is `staged` because this release changes both Python/platform
support and package topology. Staging build repairs increment the build number;
publication must promote the exact verified file without rebuilding. A release
tag or green source test alone is not evidence of public package availability.
