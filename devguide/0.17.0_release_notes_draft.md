# ArgDigest 0.17.0 — unreleased draft

ArgDigest 0.17.0 adds opt-in contract ownership for inherited implementations
and repairs alias-presence propagation and staticmethod descriptor handling.

- Set `DigestConfig(contract_owner="definition")` to use each decorated
  function's defining `module.function`, or an exact dotted key for a logical
  contract owner. The default `None` preserves existing caller resolution.
- The selected key drives aliases, standardizers, function/domain contracts and
  digester `caller`; bound methods retain runtime class identity in `qualname`.
  Configuration loaders, both decorator forms, plans and CLI audit expose it.
  A bare decorator keyword `contract_owner=...` remains digester context.
- Aliases preserve canonical explicitly supplied names for required,
  co-required and exclusive rules, including closed signatures. `*args` does
  not make an omitted keyword-only default count as supplied.
- Both staticmethod decorator orders preserve class and instance access.

Python 3.11–3.14 and core dependency floors remain unchanged. The reviewed route
uses staging and separate full/scientific and NumPy-free lower-bound installed
matrices before exact-file promotion. This draft records no qualified artifact,
publication or consumer adoption.
